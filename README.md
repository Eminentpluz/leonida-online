# LEONIDA ONLINE — unofficial GTA VI fan prototype

Browser slice of a Vice City / Leonida night: drive, steal, take iFruit jobs, pick up stars, bounce.

Not affiliated with Rockstar Games or Take-Two.

## Live URLs

- Code: https://github.com/Eminentpluz/leonida-online
- Vercel: https://leonida-online-eminentpluzs-projects.vercel.app

Vercel is deployed. If the page asks you to log in, the project still has **Deployment Protection** on. Turn it off:

1. Open [Deployment Protection](https://vercel.com/eminentpluzs-projects/leonida-online/settings/deployment-protection)
2. Disable **Vercel Authentication**
3. Reload the Vercel URL — pick Lucia or Jason and drive

To auto-deploy on every git push: Vercel project → Settings → Git → connect `Eminentpluz/leonida-online`.

Optional public backup: repo Settings → Pages → Source = GitHub Actions, then re-run the `pages` workflow. Play URL becomes `https://eminentpluz.github.io/leonida-online/`.

## Controls

| Key | Action |
| --- | --- |
| WASD | Drive / walk |
| Shift | Nitro / sprint |
| Space | Brake |
| F | Enter / exit vehicle |
| LMB | Shoot / drive-by |
| P | iFruit jobs |
| 1–4 | Start jobs |
| Esc | Pause |

Touch buttons appear on phones.
